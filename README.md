📚 Library Management System

A simple console-based Library Management System built using Java.
This project allows admins and users to manage books, members, borrowing, and returning books.

✨ Features
👨‍💼 Admin

Admin login

Add new books

Update book details

Remove books

Add new members

View all books

View all members

👤 User

User login

Borrow books

Return books

View all books

View all members

Maximum of 5 borrowed books per user

🛠️ Technologies Used

Java

ArrayList

Scanner

Object-Oriented Programming (OOP)

📁 Project Structure
LibraryManagementSystem/
│
└── LibraryManagementSystem.java

▶️ How to Run

Clone the repository:

git clone https://github.com/srisanthoshvj/Java-Library-Management.git


Open the project in any Java IDE such as IntelliJ IDEA, Eclipse, or VS Code.

Compile the program:

javac LibraryManagementSystem.java


Run the program:

java LibraryManagementSystem

🔐 Admin Login

Use the following details:

Username: admin
Password: password

📖 Borrowing Rules

A book can be borrowed only when it is available.

A user can borrow a maximum of 5 books.

A user can return only a book they have borrowed.

A borrowed book cannot be removed from the library.

🎯 Purpose

This project was created to practice basic Java programming, OOP concepts, ArrayList, classes, objects, methods, and user input.
